# Skill 加载排错

## 排查流程

当请求的 skill 无法读取或加载时：

1. 检查当前会话提供的工具及其调用方式；有 skill 加载工具时，先按名称调用并查看实际结果，不要仅凭文件搜索结果判断工具不可用。
2. 如果仍无法读取或加载，在 `~/.copilot/skills/` 和 `~/.config/github-copilot/plugins/` 下查找匹配的 skill 定义及其索引。两处存在同名 skill 时，优先使用 `~/.copilot/skills/` 中的定义。
3. 读取选中的 skill 定义及它要求的相关文件，按定义中的路径和说明加载、执行其依赖的 skill。依赖也读取或加载失败时，对该依赖重复本流程；若是索引型 skill，按索引找到对应的实际文件。
4. 只有成功获取并能够遵循所需 skill 的指令后才继续任务。若文件不存在、无法访问，或必要工具及依赖不可用，说明实际阻碍并停止，等待用户明确指示；不要声称已加载未成功加载的 skill，也不要擅自绕过其必要步骤。

例如，`grill-me` 的定义要求加载 `grilling`：应调用当前可用的 skill 加载工具并检查结果；若加载失败，再按上述目录和优先级查找，而不是直接断言工具不可用。此前排查中曾因没有实际调用工具而错误地判断其不可用，后续应以工具调用结果为准。
